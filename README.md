# Эксперимент: четыре промпта × два режима рассуждения

Одна модель решает шесть задач с вариантами A–D: три логические и три расчётные. Каждый способ запускается отдельно при двух настройках API — **48 решений и 60 вызовов** (самопромпт делает два вызова на задачу).

| Способ | Что меняется |
|---|---|
| Прямой | Только текст задачи |
| Пошагово | Добавлено «решай пошагово» |
| Самопромпт | Модель сначала пишет промпт, затем решает по нему |
| Эксперты | Одна модель пишет три независимых решения: аналитик, инженер, критик |

## Запуск

Создайте `.env` в корне проекта (ключ не попадёт в отчёт):

```dotenv
LLM_API_KEY=ваш_ключ
LLM_API_URL=https://api.example.com/v1/chat/completions
LLM_MODEL=coder-medium
```

```bash
python main.py
```

В интерактивном терминале после каждого ответа можно исправить автоматическую оценку: **Enter** — оставить, **1** — верно, **0** — неверно. Для запуска без вопросов: `python main.py --no-review`.

По умолчанию `low` отправляет `reasoning.budget_tokens=1024`, `high` — `reasoning_effort=high`. API возвращал **0 скрытых токенов рассуждения при low**, поэтому влияние бюджета **не подтверждено**: скрипт предупреждает, но продолжает прогон. Если нужно сравнить два уровня `reasoning_effort` вместо бюджета: `python main.py --reasoning-field reasoning_effort`.

## Результат

Результаты финального прогона сохранены:

- [Таблица и вывод](results/experiment.md) · [Полные ответы и метаданные](results/experiment.json)
- [Видео запуска (MP4, ~3 мин)](results/final-experiment-demo.mp4) — запись экрана добавлена и переименована; исходное разрешение сохранено.

Во всех 60 вызовах API сообщил `deepseek-ai/DeepSeek-V4-Flash-Vision-Exp`. Прямой запрос дал **6/6** при обеих настройках и потратил меньше всего токенов: 3170 (`low`) и 3790 (`high`). Самопромпт при `low` — **4/6**; остальные сочетания — **6/6**. `low` возвращал ноль скрытых токенов рассуждения, поэтому влияние бюджета 1024 **не подтверждено**. Это один прогон на шести задачах, а не общее доказательство превосходства метода.

При новом запуске `results/experiment.json` и `.md` обновятся только после всех запросов. В таблице токены и время **суммируются по шести задачам**, а у самопромпта — ещё и по обоим вызовам.

Скрипт проверяет фактический ID модели в каждом ответе и прекращает прогон при смене модели. Оценка берёт последний явно обозначенный ответ (в том числе исправленный или `\\boxed{B}`); у экспертов должны быть верны все трое. Даже после автоматической проверки просмотрите спорные ответы вручную: шесть задач и один прогон не доказывают превосходства метода.
