### Что выбрать по прогону medium

- **Qwen хватило для девяти задач:** логики, вероятности, труб, фильтрации заказов, понимания регламента, Python и планирования. Единственная ошибка — комбинаторика (`analysis_6`). Для задач такого уровня малая модель может быть достаточна, но один прогон не гарантирует устойчивости.
- **DeepSeek — быстрее и дешевле в выбранном сценарии, но точность ниже:** верно решила три математические задачи, извлечение данных и регламент. Ошиблась во всех трёх логических задачах, Python и планировании.
- **GLM — лучший баланс в этом прогоне:** 10/10 против 9/10 у Qwen, то есть **+10 процентных пунктов**. Среднее время всего на **7% больше**, при этом total-токенов примерно на **29% меньше**.
- **По выбранным публичным тарифам GLM примерно в 8,98 раза дешевле Qwen за весь набор**, несмотря на более высокую точность. У Qwen дороже выходной токен и больше выходных токенов. Это сценарная оценка, а не подтверждённое списание.
- **Расход рассуждений отличается:** GLM сообщила 2 746 reasoning-токенов, DeepSeek — 0, Qwen не сообщила этот показатель. Отправка medium всем моделям не доказывает одинаковый реальный режим.

> **Граница эксперимента:** GLM-5.3-Flash не является флагманом. Отношение стоимости относится к двум протестированным моделям, а не к флагману и малой модели.

## Тарифы и формула

Проверены **08.11.2026**, USD за **1 млн токенов**, вход без кэша, без batch-скидок и налогов.

| Тариф для сценарного расчёта | Вход / 1M | Выход / 1M | Источник |
|---|---:|---:|---|
| Qwen Cloud `qwen3.8-27b` | $0,50 | $3,00 | [Прайс Qwen](https://www.qwencloud.com/models/qwen3.8-27b) |
| DeepSeek V4 Flash, исторический off-peak | $0,22 | $0,66 | [Объявление](https://api-docs.deepseek.com/news/news260813), [таблица цен](https://api-docs.deepseek.com/img/v4_260813_price_en.png) |
| Z.ai `glm-5.3-flash` | $0,15 | $0,50 | [Прайс Z.ai](https://docs.z.ai/guides/overview/pricing) |

`Оценка в USD = (входные токены × цена входа + выходные токены × цена выхода) / 1 000 000`.

**Допущения:** для Qwen FP8 использован тариф размещённой 27B-модели, не подтверждённый тариф именно FP8-конфигурации. Для DeepSeek 0731 взят исторический тариф с 16.08.2026: off-peak; в peak оценка вдвое выше — **$0,00107184**. Это не текущая котировка старого checkpoint. Для `glm-53-flash` принято соответствие публичной `glm-5.3-flash`. Все цены — ориентиры выбранного сценария. Reasoning уже входит в выходные токены и не прибавляется повторно.

## Запуск

Python **3.10+**, без сторонних библиотек. В локальном `.env`:

```dotenv
LLM_API_URL=https://your-api.example/api/v1/chat/completions
LLM_API_KEY=ваш_ключ
```

Укажи адрес своего OpenAI-совместимого API. Для запуска нужны маршруты и соответствия моделей из `MODELS` в `main.py`; произвольный сервис может использовать другие ID.

```bash
python3 main.py
```

По умолчанию — `medium`. Для отдельного прогона с `high`:

```bash
python3 main.py --effort high
```

Три модельные очереди работают параллельно; в каждой десять задач выполняются последовательно. В терминале для каждого запроса выводятся понятное название модели, результат, время, токены (вход/выход/всего) и расчётная стоимость. В конце — итоговая таблица по моделям со счётчиком сбоев API. Пояснения к тарифам остаются в README и файле отчёта, без длинных сообщений в терминале.

Каждый ответ сразу сохраняется. Для отдельной папки (она не должна существовать):

```bash
python3 main.py --output-dir results/my-run
```

Появятся `comparison.md` — таблица и выводы, `comparison.json` — исходные ответы, запросы, параметры, время и `usage`. По умолчанию каждый запуск получает новую папку `results/YYYYMMDD-HHMMSS-ffffff`, предыдущие результаты не затираются. Эти локальные прогоны исключены из Git; для публикации оставлены `results/day5-medium-10/` и `results/day5-high-10/`.

## Что проверяем

| Задача из Дня 3 | Навык |
|---|---|
| `logic_4` | Правдолюбы и лжецы |
| `logic_5` | Конверты и истинность утверждений |
| `logic_6` | Логическая согласованность |
| `analysis_4` | Вероятность без возвращения |
| `analysis_5` | Совместная работа труб и слива |
| `analysis_6` | Комбинаторика с ограничениями |
| `extraction_1` | Фильтрация заказов и сумма по условиям |
| `reading_1` | Понимание регламента возвратов, включая границы и исключения |
| `python_trace_1` | Ссылки на списки, поверхностные и отдельные копии |
| `scheduling_1` | Минимальное расписание пяти задач для двух работников |

- **Одинаковые запросы:** прямой промпт, `temperature=0`, одинаковый `reasoning_effort` у всех моделей внутри прогона (`--effort medium` или `--effort high`), без истории, seed и заданного клиентом лимита токенов. Значение отправляется буквально, без автоматической замены.
- **Ограничение reasoning:** поддерживаемые уровни зависят от модели и конфигурации API. В частности, официальные уровни Qwen включают `xhigh`, а не `high`. Приём поля API не доказывает одинаковую интерпретацию уровня; фактический расход reasoning сохраняется отдельно.
- **Проверяемый ответ:** только `{"answer":"A"}`, буква A–D. Эталоны не отправляются моделям. Неверное решение, JSON/формат, обрезка и сбой API различаются в исходных данных.
- **Честная точность:** число засчитанных решений из шести. Ответ не той модели исключается из оценки, но расход ресурсов сохраняется.
- **Токены:** вход, выход, total и отдельно сообщённый reasoning. Не складываем reasoning повторно с total. Если часть данных отсутствует, полный расход неизвестен; известная часть сохраняется отдельно.
- **Время:** среднее, медиана и сумма времени запросов, включая сеть; это не TTFT. Параллельность может влиять на загрузку API, сумма времени не равна длительности всего прогона.
- **Стоимость:** рассчитывается по публичным тарифам и измеренным входным/выходным токенам; это оценка, не платёжный отчёт. Источники и допущения сохраняются в JSON.

Десять задач и один запуск на модель — небольшая выборка. Даже 10/10 у всех означает лишь, что этот набор не различает модели; для сложных задач и оценки устойчивости нужен отдельный эксперимент. Эталоны четырёх новых задач дополнительно проверяются тестами: вычислением суммы, применением правил, исполнением Python и перебором допустимых расписаний.

## Проверка кода

```bash
python3 -m unittest discover -v
```

Тесты используют локальный HTTP-сервер, не вызывают внешний API и не расходуют токены. `.env`, IDE, виртуальное окружение и Python-кэш исключены из Git.
