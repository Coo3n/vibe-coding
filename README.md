# День 12 · Персонализация ассистента

Агент использует три слоя памяти Lab11 и отдельный профиль пользователя. В профиле хранятся длина ответа, формат с кодом или без него, тон и список ограничений.

| Профиль | Стиль | Формат | Тон | Ограничения |
|---|---|---|---|---|
| Кратко · `short` | кратко | без кода | неформально | — |
| Подробно · `detailed` | подробно | с кодом | формально | — |
| Микс · `mix` | кратко | с кодом | формально | сразу к делу, без вступлений и извинений |

## Запуск

Используйте Python 3.9+ на macOS или Linux. Команды выполняются из папки Lab12.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
python main.py --chat
python main.py --demo
python main.py --demo --verbose --output-dir results/local-day12-example
python main.py --show-results results/offline-1/report.json
```

Меню и цветные панели соответствуют Lab11. Чат и демонстрация по умолчанию работают без сети. Локальный клиент разбирает поддерживаемые формулировки и строит ответы по шаблонам сценария о Японии, используя активный профиль и факты из переданного контекста.

Для режима API задайте `API_TOKEN`, `API_URL`, `MODEL` в корневом `.env` проекта или в окружении. Поддерживаются также `LLM_API_KEY`, `LLM_API_URL`, `LLM_MODEL`.

```bash
python main.py --chat --live
python main.py --demo --live --verbose
```

### Запуск через Codex CLI

Запускайте Lab12 из обычного терминала. Режим `--codex` использует сохранённый
вход ChatGPT в Codex CLI. Lab12 ищет `codex` в `PATH`, а на Mac также
использует встроенный CLI из `/Applications/ChatGPT.app`.
По умолчанию Lab12 явно запрашивает `gpt-6.1-terra`. Флаг `--model` переопределяет её.

```bash
python main.py --chat --codex
python main.py --demo --codex --output-dir results/local-day12-terra
```

В эксперименте `--codex` каждый вопрос появляется в консоли до запроса к
модели, а каждый ответ — сразу после получения. Итоговые таблицы выводятся в конце.

Каждый запрос ответа, извлечения предпочтений или обновления рабочей памяти
идёт отдельным ходом Codex. Перед каждым ходом Lab12 передаёт собранный массив
сообщений. Статистика включает контекст агента Codex, поэтому в этом режиме
отчёт измеряет расход всего хода и пропускает парный замер блока профиля.

## Профиль и память

В основном запросе профиль идёт отдельным сообщением system после долговременной памяти. Служебные запросы для извлечения предпочтений и обновления рабочей памяти получают профиль как данные. Агент сначала обрабатывает явные установки пользователя, затем добавляет обновлённый профиль в контекст текущего ответа.

В основном запросе пороги указаны явно. «Кратко» — максимум 90 слов на весь ответ, «подробно» — минимум 150. Формальный тон означает вежливое обращение на «Вы» с прописной буквы и без эмодзи. Неформальный тон означает простое, дружелюбное обращение на «ты».

- Команда `/profile` показывает активный профиль и доступные имена. Команда `/profile detailed` переключает профиль и начинает новый диалог с пустыми short-term и working. Долговременные факты сценария общие.
- Команда `/prefer тон: формально` явно меняет настройку. Команда `/prefer ограничение: без эмодзи` добавляет пункт в список. Профили чата хранятся в `data/profiles/` и переживают `/reset` и перезапуск. Для отдельного чата можно задать `--profiles-dir` и `--memory-file`.
- Поддерживаемая офлайн-установка в диалоге начинается, например, с «теперь», «впредь» или «в дальнейшем». «Теперь отвечай подробно, показывай примеры кода и обращайся ко мне на Вы» меняет все три поля. Разовая просьба «Покажи кодом» оставляет сохранённый профиль прежним. В режимах API и Codex предпочтения из диалога извлекает модель.
- Команды памяти из Lab11 доступны через `/help`. Команда `/context` показывает собранный контекст, включая профиль.

## Проверки

Демонстрация использует временные копии профилей и фактов. Новый прогон пишет Markdown и JSON в отдельную папку результатов.

| Проверка | Результат локального прогона |
|---|---|
| Три общих вопроса каждому профилю | «Кратко» 3/3, «Подробно» 3/3, «Микс» 3/3 |
| Десять вопросов подряд в профиле «Кратко» | 10/10, первого нарушения нет |
| Обновление профиля из реплики | Все три поля обновились и сохранились после повторной загрузки |
| Два ответа после смены предпочтений | 2/2 по длине, формату и тону |

[Офлайн-отчёт](results/offline-1/report.md) · [Полные ответы и проверки](results/offline-1/report.json)

В первом прогоне модель выбрал Codex CLI. Идентификатор `gpt-6.2-sol` подтвердил
отдельный запуск той же версии CLI с теми же настройками.
[Отчёт первого прогона через Codex CLI](results/codex-1/report.md) · [Ответы и метрики первого прогона](results/codex-1/report.json)

На `gpt-6.1-terra` завершены все три эксперимента с исходными формулировками профиля. У профиля «Подробно» 2 из 3 ответов прошли все проверки. В серии из 10 вопросов у профиля «Кратко» 1 ответ прошёл все проверки. После смены предпочтений оба ответа прошли проверки длины, формата и тона. [Отчёт Terra](results/terra-2/report.md) · [Ответы Terra и метрики](results/terra-2/report.json)

Длина измеряется числом слов. Код определяется по оформленному блоку. В новых прогонах проверка тона показывает форму обращения по местоимениям и списку распространённых повелительных форм. Нейтральная подача без явного обращения и смешанное обращение видны в проверке и не дают балл за тон. Архивные оценки сохранены по прежней методике. Формат «с кодом» оценивается на вопросах с подходящими примерами. Офлайн-прогон проверяет передачу профиля, локальный обработчик и подсчёт метрик. Архивный запуск через HTTP API завершился с HTTP 429. [Архив](results/experiment-1/report.json)

## Сценарий демонстрации

Для записи видео на уже полученных ответах откройте
`python main.py --show-results results/codex-1/report.json`. Для короткого
живого фрагмента используйте `python main.py --chat --codex`. Полный
прогон с `--demo --codex` выполняет 80 ходов Codex.

1. Запустите `python main.py --demo --verbose`. На первом вопросе сравните ответы «Кратко» и «Подробно», затем покажите таблицу трёх профилей.
2. В таблице устойчивости покажите десять вопросов, включая разовые просьбы о коде и подробностях.
3. В чате введите `/profile`, затем «Теперь отвечай подробно, показывай примеры кода и обращайся ко мне на Вы». Введите `/context` и задайте вопрос про расчёт расходов. Перезапустите чат и покажите сохранённый профиль командой `/profile`.
