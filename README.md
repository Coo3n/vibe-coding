## «Компас» — подбор путёвок с памятью

Консольный агент задаёт до **5 коротких вопросов с вариантами ответа**, ищет путёвки в учебном каталоге и продолжает диалог после перезапуска. Цветные блоки разделяют сообщения, вызовы инструментов, результаты поиска и состояние сохранённого контекста.

### Что реализовано

- **Полная история в JSON:** системная инструкция, сообщения, вызовы инструментов с аргументами и их результаты.
- **Восстановление при запуске:** агент получает всю историю; в консоли видны последние 5 ходов.
- **Поиск через tool calling:** 606 фиксированных учебных путёвок, 5 городов вылета, 6 стран и 16 курортов.
- **Строгий JSON через API:** `strict: true`, `tool_choice: required` на каждом запросе, без `auto`.
- **Наглядный контекст:** отдельно считаются реплики и технические записи; отпечаток истории позволяет сверить сохранение и загрузку.

Все отели, цены и визовые признаки учебные. Реального бронирования нет.

## Быстрый старт

Python **3.10+**, macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Настройки в локальном `.env`:

```dotenv
LLM_API_URL=https://your-api.example/api/v1/chat/completions
LLM_API_KEY=your-key
LLM_MODEL=coder
```

```bash
python main.py
```

Нужен OpenAI-совместимый API с поддержкой strict tools, `tool_choice: required` и `response_format: json_schema`. Переменные окружения приоритетнее `.env`; доступны `--env PATH` и `--model NAME`. Для маршрута `coder` используется имя `glm-53-flash`, если API не сообщил другое.

**PyCharm:** запускайте в Terminal или включите **Emulate terminal in output console**.

## Как общаться

Отвечайте номером из последнего вопроса или своим текстом. Агент выясняет:

1. Город вылета.
2. Направление и формат отдыха.
3. Даты, гибкость и количество ночей.
4. Состав группы и возраст детей.
5. Общий бюджет, отель и питание.

После пятого ответа — поиск, а не шестой вопрос. Если условия уже известны, поиск возможен раньше. Неизвестные фильтры не ограничивают выдачу, заданные условия автоматически не ослабляются. Показываются до 5 самых дешёвых подходящих вариантов.

| Команда | Действие |
|---|---|
| `/new` | Очистить историю и сразу задать первый вопрос |
| `/history` | Показать все записи с номерами, ролями и исходным JSON, включая system |
| `/exit` | Выйти с сохранением завершённого диалога |

## Как работает память

История хранится в **`data/session.json`** относительно папки проекта:

```text
system → user → assistant(tool_calls) → tool(результат) → …
```

Два инструмента:

| Инструмент | Назначение |
|---|---|
| `search_tours` | Поиск в локальном `data/tours.json` |
| `respond_to_user` | Вопрос или ответ в JSON `{ "action": "ask|answer", "answer": "…" }` |

Исходные сообщения сохраняются целиком, без пересказа и сокращения. Ответ агента находится в аргументах `respond_to_user`; соответствующий результат `accepted` подтверждает его принятие. При восстановлении старые инструменты **не выполняются заново**, их результаты помечены «ИЗ ИСТОРИИ».

После завершённого хода JSON записывается во временный файл, сбрасывается через `fsync` и атомарно заменяет предыдущий. При ошибке API или сохранения незавершённый ход отменяется. Максимум **5 запросов к LLM на одно сообщение пользователя** — отдельно от лимита вопросов за весь подбор.

## Проверка задания

1. Начать подбор, ответить на часть вопросов и выйти.
2. Запустить снова — увидеть прежние сообщения и продолжить без повторного опроса.
3. Получить путёвки через `search_tours`, выйти и запустить приложение повторно.
4. Попросить вспомнить ID, цены и характеристики **без нового поиска** — ответ должен опираться на сохранённую выдачу.

## Каталог и структура

Вылеты — **июнь–сентябрь 2027**, поездки на 5/7/10/14 ночей, 1–4 взрослых, 0–2 детей, отели 3–5★, питание BB/HB/AI. Все сочетания условий не гарантируются: возможна пустая выдача.

```text
app/agent.py                 цикл агента и ограничения опроса

app/response.py              строгий формат ответа
app/history.py               проверка, сохранение и загрузка истории
app/tools.py                 инструменты поиска и ответа
app/cli.py                   консоль и команды
data/tours.json              606 учебных путёвок
data/tours.base.json         6 контрольных предложений
scripts/generate_catalog.py  воспроизводимая генерация остальных 600

```

Повторно создать тот же каталог: `python scripts/generate_catalog.py` (фиксированный seed `707`).

### Ограничения

Работайте в **одном экземпляре приложения**: блокировок конкурентной записи нет. JSON не зашифрован; история, `.env` и ключи исключены из Git. При остановке посреди ответа восстанавливается последний завершённый ход. История не усекается и со временем может достичь контекстного лимита API. Строгий JSON гарантирует формат, но не истинность текста LLM: источник фактов — результаты инструмента поиска.
