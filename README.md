## Задача

Сравнить три стратегии памяти агента на одном диалоге о поездке в Японию:
Sliding Window, Sticky Facts и Summary. Добавить переключение стратегий,
checkpoints и независимые ветки диалога. Сценарий и методика проверки взяты из `Lab10.zip`.

## Результаты

Последний завершённый прогон: модель **`coder`**, окно **4 сообщения**,
8 ходов диалога и 10 контрольных вопросов на каждую стратегию.

| Стратегия | Автооценка | По смыслу ответов¹ | Токены всего | Из них память | API всего | Из них память | Строк класса² |
|---|---:|---:|---:|---:|---:|---:|---:|
| Sliding Window | 4/10 | **1/10** | 43 995 | 0 | 18 | 0 | 17 |
| Sticky Facts | 10/10 | **10/10** | 50 663 | 17 283 | 36 | 18 | 42 |
| Summary | 6/10 | **3/10** | 195 836 | 102 246 | 50 | 32 | 44 |

¹ Ручная сверка сохранённых ответов. Автооценка по ключевым словам завышает результат:
название места среди предложенных вариантов не означает, что агент помнит договорённость,
а `20` внутри `2026` не означает правильный дедлайн «20 марта».
Исходные автоматические оценки в JSON не исправлялись.

² Строки классов на момент прогона, включая комментарии; ориентир сложности, не оценка качества.
Служебные токены и вызовы памяти **уже включены** в общий итог.

### Выводы

- **Sticky Facts — лучший результат этого прогона:** все десять проверяемых деталей сохранены,
  расход лишь на **15,2% выше Sliding Window**.
- **Sliding Window** забыла почти все ранние детали. В ответах появились выдуманные города,
  июньские даты и суммы в долларах, которых пользователь не задавал.
- **Summary** потребовала в **3,9 раза больше токенов, чем Sticky Facts**, но потеряла бюджет,
  город вылета, ограничения по еде и другие договорённости. На её обновление ушло 32 вызова
  и **52,2% всего расхода** этой стратегии.

| Сценарий | Подходящая стратегия |
|---|---|
| Короткие независимые вопросы, история не важна | Sliding Window |
| Долгая работа с бюджетом, сроками, ограничениями и решениями | Sticky Facts |
| Связный разговор и повествовательные нюансы | Summary с контролем размера и частоты обновления |

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

В `.env` в корне проекта:

```dotenv
LLM_API_URL=https://example.com/v1/chat/completions
LLM_API_KEY=your-api-key
LLM_MODEL=your-model
```

Поддерживаются также `API_URL`, `API_TOKEN`, `MODEL`; `LLM_*` имеют приоритет.
URL может быть полным endpoint, базовым адресом сервера или адресом с `/v1`.
Ключи и локальные прогоны не входят в Git.

```bash
python main.py --demo
python main.py --case summary
python main.py --chat --strategy sticky --window 6
python main.py --demo --output-dir results/my-run
python main.py --show-results results/experiment-1/report.json
```

Без аргументов открывается меню. Дополнительно: `--env путь`, `--model имя`,
`--verbose` для полных ответов в диалоге эксперимента.

## Стратегии и ветки

| Стратегия | Контекст запроса | Поддержка памяти |
|---|---|---|
| `sliding` | system + последние N сообщений | Старые сообщения удаляются, служебных вызовов нет |
| `sticky` | system + JSON-словарь facts + последние N сообщений | Facts обновляются после каждого сообщения пользователя |
| `summary` | system + резюме + последние N сообщений | Выпадающие сообщения добавляются в резюме |

Системная инструкция и блок памяти в N не входят. При смене стратегии её память
начинается с нуля. У sticky/summary полная история остаётся локально для просмотра.

Команды: `/strategy sliding|sticky|summary`, `/window N`, `/facts`, `/summary`,
`/history`, `/checkpoint имя`, `/branch имя`, `/switch имя`, `/tree`, `/reset`, `/help`, `/exit`.

Пример двух независимых продолжений:

```text
Планируем поездку в Японию, бюджет 250 тысяч рублей на человека.
/checkpoint поездка
/branch эконом
В этой ветке бюджет — 180 тысяч рублей.
/switch поездка
/branch комфорт
В этой ветке бюджет — 350 тысяч рублей.
/switch эконом
Какой бюджет мы выбрали?
/switch комфорт
Какой бюджет мы выбрали?
/tree
```

Снимок копирует историю, стратегию, facts/summary и окно. `/checkpoint` оставляет в текущей
ветке, `/branch` создаёт новую и переходит в неё. `/reset` очищает только текущую ветку.
Повторяющиеся имена не перезаписываются. Ветки хранятся в памяти процесса до выхода.

## Методика и ограничения

Для всех стратегий одинаковые сообщения пользователя и контрольные вопросы.
Ответы генерируются отдельно; вопросы идут последовательно и пополняют историю.
В архиве заявлены 15 деталей, но проверяются десять вопросов — это не проверка всех деталей.
Оценка по ключевым словам приблизительная, полные ответы требуют сверки.

Полный расход = диалог + вопросы + поддержка памяти. Счётчик API означает логические
вызовы, не повторные сетевые попытки. При отсутствии `usage.total_tokens` прогон
останавливается: неизвестный расход не считается нулём.

Каждый новый эксперимент сохраняет `report.json` и `report.md` в `results/local-day10-*`
или новую папку `--output-dir`. При ошибке сохраняются причина остановки и завершённые
стратегии. Существующая папка не перезаписывается.

Код: `app/cli.py` — консоль; `app/agent.py` — история и ветки; `app/context.py` — стратегии;
`app/client.py` — API; `app/scenario.py` — сценарий; `app/experiment.py` — сравнение;
`app/report.py` — отчёты. Точка входа — `main.py`.
